个人网站内容准备清单
====================

一、基本信息
[ ] 网站名称
[ ] 个人昵称
[ ] 一段简短的个人介绍
[ ] 对外公开的联系方式

二、博客内容
[ ] 准备第一篇自我介绍文章
[ ] 整理两到三篇已有笔记
[ ] 为每篇文章填写标题、摘要、日期和标签
[ ] 检查外部链接是否有效

三、公开文件
[ ] 确认文件拥有公开分享权限
[ ] 删除身份证、密码、私人地址等敏感信息
[ ] 使用清楚且不带空格的文件名
[ ] 准备文件用途说明

四、上线检查
[ ] 检查手机与电脑显示效果
[ ] 检查导航与文章链接
[ ] 实际下载一次所有公开文件
[ ] 确认 GitHub 仓库不包含私人信息
[ ] 绑定域名前测试平台提供的网址
